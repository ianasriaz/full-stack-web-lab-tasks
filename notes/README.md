# Notes

Preparation material that is **never submitted**. The instructor receives only the lab
folder (solution + source); everything that would look like coursework scaffolding —
viva prep, implementation logs, the story of how the app was built — lives here instead.

## Mapping

| Lab | Submission folder | Notes |
|-----|-------------------|-------|
| Lab 05 | [`../Lab05-EFCore-Database/`](../Lab05-EFCore-Database/) | [`Lab05/`](./Lab05/) — README, IMPLEMENTATION, VIVA |

## Contents of `notes/Lab05/`

| File | Purpose |
|------|---------|
| `README.md` | The task, the deliverable, how to run it, recorded proof. |
| `IMPLEMENTATION.md` | Chronological log of what changed and why. |
| `VIVA.md` | Likely viva questions with short answers. |

## Rule
Nothing in `notes/` is copied into a submission folder. Keep coursework markers
(Lab, Task, Viva, Implementation) out of the submission folders themselves.
